# adityarao.net

## Description
This is my personal website which I plan to use as a portfolio, blog and digital garden.

This isn't my first website though. I had two previous **'versions'** with different domains and different tech powering them.
First was a [Jekyll](https://jekyllrb.com/) blog with domain **_raoaditya.com_** and second was a portfolio website created using [Gatsby.js](https://www.gatsbyjs.com/) using domain **_adityarao.dev_**

I do not own the two domains anymore, but I have kept the repos at GitHub.
- [raoaditya.github.io](https://github.com/thisisadityarao/raoaditya.github.io)
- [adityarao.dev](https://github.com/thisisadityarao/adityarao.dev)

I'm using [Astro](https://astro.build/) to make the current website. I will also use [Pi](https://pi.dev/) coding harness with a capable model to assist me in creating and maintaining this website.

Initially, I was torn between using an AI/LLM to create my personal website vs hand coding it. Now, I have embraced LLMs knowing that they aren't going anywhere, and how huge productivity boost they are. I can spin-up an Astro template in seconds, while a LLM can make a similar static website in a couple of minutes with proper guidance, assets and tools. Although fun (for many), hand-coding a website (even simple static sites) will take significantly longer time compared to LLMs.
